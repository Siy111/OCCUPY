# 占城棋游戏规则

## 一、总体介绍
占城棋是一款双人策略陆战棋类游戏，对局在网格棋盘上进行，双方交替回合展开博弈。

游戏的基本目标是进攻或围困敌方城池，争夺棋盘上的资源点，在战役中占据更多残骸，从而在结算中取得最终胜利。

![占城棋游戏规则](/assets/general_view.jpg)

## 二、元素介绍
### 1. 棋盘
  包含`72×72`格的网格棋盘，每一小格称为**格点**。除棋盘外各元素均落在格点中。
### 2. 棋子
   - `◯`：圈棋子
   - `✕`：叉棋子
   - `⨂`：残骸

规格均为`1×1`。圈棋子属于圈方，叉棋子属于叉方。残骸由吃子得到，不属于任何一方。棋子均对走子构成**阻碍**。
### 3. 资源点
   - `▩`：资源点

  规格为`1×1`。资源点对走子构成**阻碍**。
### 4. 城池
   - 圈方主城。

  ![主城-圈](/assets/circle-main.jpg)
   - 叉方主城。

  ![主城-叉](/assets/cross-main.jpg)

  主城规格为`7×7`，内城规格为`3×3`。内城不可放置棋子，对走子构成阻碍。外城为主城除内城的部分，对己方走子不构成阻碍；对敌方构成阻碍，直到被攻破。
   - 副城。

  ![副城1](/assets/sub.jpg)

  副城规格为`5×5`，开局为空，对双方均不构成阻碍。先进入副城的占领该城，此时该城对另一方构成阻碍，直到被攻破。

## 三、游戏流程
### 1.开局
玩家分出先后手。先手在任意位置不重叠地布置：叉方主城 1 座、圈方主城 1 座、副城任意多座、资源点任意多个、叉棋子 1 颗、圈棋子 1 颗。后手率先选定一方棋子，进行**走子**或**吃子**，称为**一手**，随后双方交替各走一手直至终局。

叉、圈棋子可被放置在各自的主城外城中。
### 2.走子

![走子](/assets/move.png)

可从己方任一颗棋子往一个与**该棋子同处于3×3区域**的空格点走一颗棋。走子需**起点与终点的连线上没有阻碍**。
### 3.吃子

![吃子](/assets/eat.png)

可从己方任一颗棋子发起吃子。若**以攻击方为中心的3×3区域内**己方棋子与己方城池空格点数量的和大于敌方棋子数，则可杀死本区域内一颗敌方棋子，使其变为**残骸**。
### 4.占城
游戏开局时，副城为空。率先走子进入的一方获得副城，对方无法再走入，直到此城被攻破。
### 5.攻城
对敌方的主城和副城发起攻击。当敌城**四面城墙下**(不包括两面墙交汇点)均存在己方棋子，可走入敌城，走入后该城被攻破。
### 6.围城
对于任意一座城，若无法从中心点通过**连续走子**到达棋盘边界，则该城被**围死**。

连续走子，指按照走子规则走到空格或己方棋子上，递推下去。

## 四、判胜条件
### 1.攻破敌方主城
当某一方**攻破**敌方主城时，该方为胜方。
### 2.围死敌方主城
当某一方**围死**敌方主城时，该方为胜方。
### 3.结算战果
在对局中，当双方一致同意结算战果，可统计：
- 残骸归属： 对每一个残骸，在**以它为中心的3×3区域**内，若一方棋子数量大于敌方，则该方获得该残骸，分数加1。
- 资源点归属： 对每一个资源点，在**以它为中心的3×3区域**内，若一方棋子数量大于敌方，则该方获得该资源点，分数加1。
- 副城兵力： 己方**未被攻破或围死**的副城内己方棋子数量。每颗棋子分数加1。

**总分数高**的一方获胜。

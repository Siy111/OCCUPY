# 占城棋规则

## 一、总体介绍
占城棋是一种回合制双人策略陆战棋类游戏。

游戏的基本目标是进攻或围困敌方城池，争夺资源点，占据更多残骸，从而在结算中取得最终胜利。

![占城棋游戏规则](/assets/general_view.jpg)

## 二、元素介绍
### 1. 棋盘
  包含`72×72`格的网格棋盘。
### 2. 棋子
   - `◯`：圈方棋子
   - `✕`：叉方棋子
   - `⨂`：残骸

规格均为`1×1`格。残骸通过**吃子**产生。
### 3. 资源点
   - `▩`：资源点

  规格为`1×1`格。
### 4. 城池
  - 圈方主城。

  ![主城-圈](/assets/circle-main.jpg)
  
  - 叉方主城。

  ![主城-叉](/assets/cross-main.jpg)

  主城规格为`7×7`格，分内、外城。中心的`3×3`格是内城，其余部分是外城。内城不可放置棋子，不可走子。外城允许己方走子，除非城被攻破或围死，否则敌方不可走子。
  
  - 副城。

  ![副城1](/assets/sub.jpg)

  副城规格为`5×5`格，开局为空城。先进入副城的一方占领该城，此时除非城被攻破或围死，否则另一方不可走子。

## 三、游戏流程
### 1.开局
玩家分出先后手，初始化棋盘。

先手布置：叉方主城 1 座、圈方主城 1 座、副城若干、资源点若干。随后在棋盘上放叉、圈棋子各 1 颗。除城外空格点上，初始棋子还可放在各自主城的外城中。

后手率先选定一方，先手选另一方。由后手开始，每回合双方轮流进行一次**走子**或**吃子**，称为**一手**，直至终局。

### 2.走子

![走子](/assets/move.png)

在棋盘上增加一颗棋子。以己方棋子为起点，向**与该棋子同处一个3×3区域**，且**与起点的连线上没有阻碍**的空格上增一颗己方棋子。
### 3.吃子

![吃子](/assets/eat.png)

吃掉一颗敌方棋子。若**以己方棋子为中心的3×3区域内**，己方棋子与己方城池空格数量的和大于敌方棋子数，则可将该区域内一颗敌方棋子变为**残骸**。
### 4.占城
率先走子进入空的副城。可以获得该城，敌方无法再走入，直到此城被攻破或围死。
### 5.攻城
进攻敌方城池。当敌城**四面城墙下**(不含两面墙交汇点)均存在己方棋子时，可走入敌城，走入后该城被**攻破**。
### 6.围城
包围敌方城池。当一座城，无法从它的中心通过**连续走子**到达棋盘边界时，该城被**围死**。

连续走子，指按照走子规则走到空格或己方棋子上，并不断递推下去。

## 四、判胜条件
### 1.攻破敌方主城
先**攻破**敌方主城的一方获胜。
### 2.围死敌方主城
先**围死**敌方主城的一方获胜。
### 3.结算战果
在对局中，当双方一致同意，可统计：
- 残骸归属： 对每一个残骸，**以它为中心的3×3区域内**，棋子数量大于敌方的获得此残骸，加1分。
- 资源点归属： 对每一个资源点，**以它为中心的3×3区域内**，棋子数量大于敌方的获得此资源点，加1分。
- 副城兵力： 双方**未被攻破或围死的副城内**己方棋子数量。每颗棋子加1分。

**总分数高**的一方获胜。
